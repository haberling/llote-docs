Philosophy & FAQ

Does llote use AI to write anything? No. ask only ever returns a line you already wrote, verbatim. It never generates text.

Does anything leave my machine? Only a one-time download of the local search model, the first time you run ask or setup. Your notes never do.

Why "llote"? llm + note — search by meaning, not exact wording.
