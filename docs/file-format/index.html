File Format

Plain text, append-only, human-editable.

text
#llote-id:3fae1c2e-9d7b-4b3a-8c1e-2a1e6f9d1234
2026-09-03T14:02:11-05:00	bought milk
2026-09-03T14:07:44-05:00	call dentist tomorrow

Line one is a header llote uses to key its own search cache in app data — never a sidecar file next to your notes. Every other line is a timestamp and your text, tab-separated. Hand-edit it, back it up, put it in git — it's just text.
